## **Артиллерийские Дуэли - Сетевая игра**

**Краткая концепция:**
Многопользовательская пошаговая артиллерийская дуэль на разрушаемой карте с физикой снарядов.

**Основной геймплей:**
- 2-4 игрока по очереди стреляют из танков
- Настройка угла и мощности выстрела
- Учет ветра и физики полета снаряда
- Разрушаемый ландшафт
- Побеждает последний выживший

**Техническая суть:**
- **Сервер:** управляет игровой логикой, физикой, рассылкой состояния
- **Клиенты:** PyQt GUI с отрисовкой поля, управлением и чатом
- **Сеть:** TCP + многопоточность + кастомный протокол на pickle
- **Особенности:** разрушаемая местность, случайный ветер, система комнат

**Протокол сообщений:**
`signup`, `move`, `shot`, `game_state`, `chat`, `exit_game`
